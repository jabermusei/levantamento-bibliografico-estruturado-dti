# Política de dados restritos

O repositório público contém o protocolo, as strings, os registros metodológicos, as decisões, os hashes e os instrumentos autorais necessários à auditoria do levantamento.

Não são publicados automaticamente:

- exportações brutas da Scopus, Web of Science ou de outras bases sujeitas a contrato;
- PDFs e textos integrais protegidos por direitos autorais;
- credenciais, tokens ou configurações locais;
- evidências de interface que contenham elementos de conta ou da sessão do pesquisador;
- arquivos binários de trabalho não liberados para redistribuição.

Os arquivos restritos são preservados localmente ou em armazenamento institucional controlado. Quando necessário à rastreabilidade, o repositório público informa nome, data, tamanho, proveniência e hash SHA-256, sem redistribuir o conteúdo.
