# Módulo 2 — Caso China

Módulo próprio para fontes acadêmicas e documentais do caso China. Permanece fechado até a conclusão e o registro das buscas iniciais do Módulo 1. Materiais anteriores sobre China não integram automaticamente este corpus.

As etapas internas são: planejamento/strings; exportações brutas; triagem instrumental; fontes selecionadas; análise documental.
