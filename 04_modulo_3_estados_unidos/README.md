# Módulo 3 — Caso Estados Unidos

Módulo próprio para fontes acadêmicas e documentais do caso Estados Unidos. Permanece fechado até a conclusão e o registro das buscas iniciais do Módulo 1. Materiais anteriores sobre Estados Unidos não integram automaticamente este corpus.

As etapas internas são: planejamento/strings; exportações brutas; triagem instrumental; fontes selecionadas; análise documental.
